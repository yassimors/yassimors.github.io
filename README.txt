APERÇU 3D DU CAFTAN — VERSION CORRIGÉE

Fichiers:
- caftan.glb : modèle 3D optimisé avec compression géométrique glTF standard, env. 8,7 Mo
- index.html : visualiseur interactif avec message d’erreur si le GLB manque ou ne se charge pas

Pour GitHub Pages:
1. Placez index.html et caftan.glb dans le même dossier (à la racine du site, sauf si vous adaptez le chemin).
2. Respectez exactement le nom caftan.glb (GitHub Pages distingue majuscules et minuscules).
3. Activez GitHub Pages dans Settings > Pages.
4. Vérifiez d’abord que https://VOTRE-SITE/caftan.glb ouvre/télécharge le fichier, puis rechargez la page.

Pour prévisualiser localement:
  python3 -m http.server 8000
Puis ouvrez http://localhost:8000.

La page charge model-viewer depuis Google CDN (connexion Internet requise). Le modèle est optimisé pour la compatibilité web; les broderies les plus fines peuvent être moins détaillées que dans le fichier source. Le modèle a été généré à partir de la photo de face; les côtés et l’arrière sont estimés. Ce n’est pas un scan de précision ni un patron de confection.
