APERÇU 3D DU CAFTAN — VERSION OPTIMISÉE

Fichiers:
- caftan.glb : modèle 3D texturé et compressé (GLB / glTF 2.0, env. 3,5 Mo)
- index.html : exemple de visualiseur interactif basé sur <model-viewer>

Pour prévisualiser:
1. Placez index.html et caftan.glb dans le même dossier.
2. Servez le dossier via HTTP (par exemple: python3 -m http.server 8000).
3. Ouvrez http://localhost:8000 dans un navigateur récent.

Pour intégrer à un site, hébergez caftan.glb et adaptez l’attribut src du composant <model-viewer>.
Le visualiseur charge model-viewer depuis Google CDN; un accès Internet est donc nécessaire.

Le modèle a été compressé (géométrie Meshopt et textures réduites à 1024 px) afin de diminuer le poids pour le web. Certaines très fines broderies peuvent être moins détaillées que dans l’original.

Note: modèle visuel estimé à partir de la photo de face, les côtés et l’arrière sont estimés. Ce n’est pas un scan de précision ni un patron de confection.
